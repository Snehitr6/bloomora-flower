# 🌸 Bloomora — Flowers & Gifts

A modern, premium **flower & gift e-commerce website** built with React, Vite, and Tailwind CSS. Bloomora provides a beautiful shopping experience for discovering bouquets, flowers, gifts, and special collections.

## ✨ Features

- 🌷 Premium Bloomora landing page
- 💐 Shop flowers and gift collections
- 🌹 Roses, Lilies, Orchids, Sunflowers & Mixed collections
- 🔍 Product search and filtering
- 🛍️ Add products to cart
- ❤️ Wishlist functionality
- 📦 Cart and checkout flow
- 👤 Login and signup pages
- 🧾 Order confirmation page
- ⭐ Customer reviews/testimonials
- 📱 Fully responsive mobile-first design
- ✨ Smooth scroll animations
- 🎬 Premium opening/preloader animation
- 🧭 Fixed responsive navigation
- 🌙 Modern premium floral design
- 💾 Cart and wishlist persistence using localStorage
- ⚡ Fast Vite development environment

## 🛠️ Tech Stack

- **React.js**
- **Vite**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **React Router DOM**
- **Lucide React**
- **HTML5**
- **CSS3**
- **LocalStorage**
